# Papelaria Rabisco

Site institucional da Papelaria Rabisco — papelaria criativa e personalizada
(planners com nome, papel de carta ilustrado por parceiros locais, oficinas
de scrapbook aos sábados) em São Bernardo do Campo.

Vite + React + TypeScript + Tailwind CSS v4, motion animations, direção
visual em contrato (Alfa Slab One + Manrope, canvas pêssego, cartões com
borda preta, ilustrações de linha desenhadas à mão).

## Rodando localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
